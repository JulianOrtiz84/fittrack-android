# Wireframe — interfaz de dos paneles

```text
┌───────────────────────┬──────────────────────────────────────────┐
│ FITTRACK              │ Perfil                                   │
│ Tu bienestar...       │ Datos y objetivos personales              │
│                       │                                          │
│ ●  Perfil             │ ┌──────────────────────────────────────┐ │
│ ▣  Fotos              │ │ Tu perfil de bienestar                │ │
│ ▶  Video              │ │ [acción de la sección]                │ │
│ ⌘  Web                │ └──────────────────────────────────────┘ │
│ ↗  Botones            │                                          │
│                       │                                          │
│ Entrega 1             │                                          │
└───────────────────────┴──────────────────────────────────────────┘
```

En todas las orientaciones, el panel izquierdo conserva el menú y el derecho cambia según la selección, conforme al requisito de fragments simultáneos. En teléfonos se compactan los márgenes y componentes; el panel derecho se desplaza verticalmente cuando el contenido supera el alto visible. En la segunda entrega, cada opción tiene una acción propia:

- **Perfil:** editar datos personales, académicos y de experiencia.
- **Fotos:** consultar ejercicios ilustrados con descripción y agregar fotos personales a la galería.
- **Video:** abrir la rutina completa de ATHLEAN-X Español o elegir un archivo local para reproducirlo con controles integrados.
- **Web:** digitar una URL y consultarla en una vista integrada; inicia con la página de actividad física de la OMS.
- **Botones:** guardar o cancelar una nota de bienestar.
