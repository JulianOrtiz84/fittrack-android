# Wireframe — interfaz de dos paneles

```text
┌───────────────────────┬──────────────────────────────────────────┐
│ FITTRACK              │ Perfil                                   │
│ Tu bienestar...       │ Datos y objetivos personales              │
│                       │                                          │
│ ●  Perfil             │ ┌──────────────────────────────────────┐ │
│ ▣  Fotos              │ │ Tu perfil de bienestar                │ │
│ ▶  Video              │ │ [acción de la sección]                │ │
│ ⌘  Web                │ └──────────────────────────────────────┘ │
│ ↗  Botones            │                                          │
│                       │                                          │
│ Entrega 1             │                                          │
└───────────────────────┴──────────────────────────────────────────┘
```

El panel izquierdo conserva el menú visible; el derecho cambia según la selección.
